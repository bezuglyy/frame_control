# Управление рамкой

Кастомная интеграция Home Assistant · v6.0.0

![icon](custom_components/frame_control/brand/icon.png)
Управление цифровой фоторамкой/дисплеем (Android-рамка): включение, яркость, сценарии.

## Возможности
- Управление питанием рамки (кнопки, переключатели)
- Яркость, сценарии, расписание (часы)
- Мониторинг состояния (сенсоры)
- Интеграция с Android TV / рамкой по сети

## Установка
Скопируйте папку `custom_components/frame_control/` в каталог `custom_components/` конфигурации HA и перезапустите Home Assistant.
