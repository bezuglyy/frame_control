## Описание
Управление цифровой фоторамкой/дисплеем (питание, яркость, сценарии, расписание).
### Возможности
- Кнопки и действия
- Числовые настройки и параметры
- Сенсоры и мониторинг состояния
- Переключатели и вкл/выкл устройства
### Установка
1. Скопируйте папку `custom_components/frame_control/` в каталог `custom_components/` конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Управление рамкой**.
> Установка через HACS: добавьте репозиторий `https://github.com/bezuglyy/frame_control` как Custom repository (категория Integration).

## Description
Digital photo frame / display control (power, brightness, scenes, schedule).
### Features
- Buttons and actions
- Number settings and parameters
- Sensors and state monitoring
- Switches and on/off controls
### Installation
1. Copy the `custom_components/frame_control/` folder into the `custom_components/` directory of your Home Assistant configuration.
2. Restart Home Assistant.
3. Settings → Devices & Services → Add Integration → **Управление рамкой**.
> HACS: add `https://github.com/bezuglyy/frame_control` as a Custom repository (category Integration).
