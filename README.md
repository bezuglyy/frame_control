# Управление рамкой
Кастомная интеграция для [Home Assistant](https://www.home-assistant.io) · версия **6.0.0**.
![icon](custom_components/frame_control/brand/icon.png)
| | |
|---|---|
| Домен | `frame_control` |
| Версия | 6.0.0 |
| Тип | custom integration |
## Описание
Управление цифровой фоторамкой/дисплеем (питание, яркость, сценарии, расписание).
## Возможности
- Кнопки и действия
- Числовые настройки и параметры
- Сенсоры и мониторинг состояния
- Переключатели и вкл/выкл устройства
## Установка
1. Скопируйте папку `custom_components/frame_control/` в каталог `custom_components/` конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Управление рамкой**.
> Установка через HACS: добавьте репозиторий `https://github.com/bezuglyy/frame_control` как Custom repository (категория Integration).
